# StylePilot AI

A responsive fashion-marketing assistant prototype for independent clothing brands and online sellers.

## Current features

- Product image preview (the image stays in the browser; it is not uploaded).
- Product name, category, product details and brand-voice inputs.
- Product descriptions, Instagram captions and ad copy generated from editable local templates.
- Copy-to-clipboard actions.
- Tavily-powered fashion-market web research through a private Flask backend.
- Source links with relevance labels and an evidence summary.
- A basic marketing-plan draft based on sources classified as relevant.

## Run locally on Windows

1. Install Python 3.10 or newer.
2. Open Command Prompt in the project folder.
3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Copy `.env.example` to `.env` and add your private Tavily API key to `TAVILY_API_KEY`. Never paste the key into chat or commit `.env` to GitHub.
5. Start the app:

   ```bash
   python app.py
   ```

6. Open http://127.0.0.1:5000.

The research feature needs the Flask server. Opening `index.html` directly or using the static GitHub Pages site will not provide the private backend endpoint.

## Deployment note

For a Python hosting service, install `requirements.txt` and start the app with:

```bash
gunicorn app:app
```

Set `TAVILY_API_KEY` in the host's private environment variables. If the platform requires an explicit bind address, set `HOST=0.0.0.0` and use its supplied `PORT`. Do not expose the key in frontend JavaScript.

## Honest feature boundaries

- Product copy is currently generated from local JavaScript templates; it is not generated by an AI model.
- Tavily powers the web-search request only. Search snippets and automated relevance labels are not proof of sales, demand or current stock; open and verify source pages.
- The marketing plan is a lightweight draft based on returned source snippets, not a validated market forecast.
- Virtual try-on is a planned concept and is not implemented or connected.
