# StylePilot AI

A responsive fashion marketing assistant prototype for independent clothing brands and online sellers.

## Features
- Product image preview
- Product name, category, details, and brand voice inputs
- Product descriptions, Instagram captions, and ad copy generated from local templates
- Copy-to-clipboard buttons
- Virtual try-on feature concept section

## Run locally
Open `index.html` in a modern browser. No build tools or installation are required.

## Demo limitations
This is a front-end prototype. Text is generated using local JavaScript templates and is **not connected to an AI model or API**. The virtual try-on section is a planned feature and is **not implemented or connected**.

## Vision
Make professional fashion marketing tools more accessible to small fashion brands and independent sellers.
